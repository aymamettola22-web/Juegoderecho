# Desafío: Derecho a la vida

Juego web educativo: 10 preguntas de desarrollo, temporizador de 5 minutos, puntaje automático de 1 punto por respuesta completada (máximo 10) y diseño pastel amarillo, crema, rosa y lavanda.

## Publicar en GitHub Pages
1. Creá un repositorio y subí `index.html`, `style.css` y `script.js`.
2. Entrá en **Settings → Pages**.
3. En **Build and deployment**, elegí **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guardá.

## Envío de respuestas
GitHub Pages no puede mandar emails ni SMS automáticamente sin un servicio externo y configuración adicional. Los botones abren el correo o los mensajes con el texto preparado; la persona debe confirmar el envío. No publiques claves secretas en el repositorio.
